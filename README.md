# 돈 거래 장부

지인들과 돈을 빌리고 갚은 내역을 날짜·금액 단위로 기록하고, 빌린 돈 / 갚은 돈 / 남은 잔액을
한눈에 볼 수 있는 정적 웹페이지입니다. GitHub Pages로 배포하며, 장부 데이터는 **비밀번호로
암호화**되어 올라가므로 비밀번호를 공유한 사람만 볼 수 있습니다.

## 파일 구성

- `index.html` — 전체 앱 (화면, 계산, 암호화 로직 포함, 외부 의존성 없음. 글꼴만 CDN)
- `data/main.enc.json` — 암호화된 장부 데이터 (처음에는 없음. 앱에서 만들어 올림)

## 처음 시작하기

1. 이 폴더를 GitHub 저장소로 올리고 **Settings → Pages → Deploy from a branch → main / (root)** 로 배포합니다.
2. 배포 주소(`https://<계정>.github.io/<저장소>/`)를 열면 장부 파일이 없어서 **"새 장부 만들기"** 화면이 뜹니다.
   (로컬에서 `index.html`을 더블클릭해도 같은 화면이 나옵니다.)
3. 장부 주인 이름과 비밀번호를 정하고, 편집 모드에서 내역을 입력합니다.
4. **"저장 파일 내려받기"** 로 받은 `main.enc.json`을 저장소의 `data/` 폴더에 넣고 push 합니다.
5. 1~2분 뒤 배포 주소에서 비밀번호를 입력하면 장부가 열립니다. 이 주소와 비밀번호를 지인에게 공유하세요.

## 내역 수정하는 방법

1. 배포 주소를 열어 비밀번호로 로그인 → **편집** 버튼
2. 내역 추가 / 수정 / 삭제 (화면 위쪽에 "저장하지 않은 변경사항" 배너가 뜸)
3. **저장 파일 내려받기** → 받은 `main.enc.json`을 `data/`에 덮어쓰고 push

지인들은 화면에서 편집 버튼이 보이더라도 GitHub에 push 할 수 없으므로 실제 데이터를 바꿀 수 없습니다.
(내려받은 파일을 직접 올려야만 반영됩니다.)

## 입력 구분

| 구분 | 의미 |
|---|---|
| 빌림 | 장부 주인이 지인에게 돈을 빌림 (빌린 돈 증가) |
| 갚음 | 장부 주인이 빌린 돈을 갚음 (잔액 감소) |
| 빌려줌 | 장부 주인이 지인에게 돈을 빌려줌 |
| 돌려받음 | 빌려준 돈을 돌려받음 |

빌린 돈과 빌려준 돈은 각각 따로 집계되고, 사람별 카드와 거래 내역 표에서 **거래 후 잔액**을 볼 수 있습니다.
CSV 내보내기도 지원합니다.

## 사람마다 다른 장부·비밀번호 쓰기 (선택)

한 비밀번호를 공유하면 모든 지인이 서로의 거래까지 볼 수 있습니다. 서로 안 보이게 하려면
주소 뒤에 `?l=이름`을 붙여 장부를 나누세요.

- `https://…/` → `data/main.enc.json`
- `https://…/?l=철수` → `data/철수.enc.json`

`?l=철수` 주소로 들어가 장부를 만들고 저장하면 `철수.enc.json`이 받아집니다. 이름별로 다른 비밀번호를 쓰면 됩니다.

## 보안 안내

- 암호화: PBKDF2-SHA256(60만 회) → AES-256-GCM. 브라우저 안에서만 암호화·복호화하며 비밀번호는 어디로도 전송되지 않습니다.
- 저장소가 공개(public)이면 암호화된 파일은 누구나 내려받을 수 있습니다. 비밀번호가 짧으면 무차별 대입으로 풀릴 수 있으니
  **12자 이상의 추측하기 어려운 비밀번호**를 쓰세요. 비공개(private) 저장소 + Pages를 쓸 수 있으면 더 안전합니다.
- 비밀번호를 잊으면 복구할 수 없습니다. `main.enc.json`은 git 기록에 남으니 백업이 필요 없지만, 비밀번호는 따로 보관하세요.
- "이 기기에서 로그인 유지"를 켜면 그 브라우저의 localStorage에 비밀번호가 저장됩니다. 공용 PC에서는 켜지 마세요.
- 비밀번호를 바꾸면 이미 push 된 과거 파일은 이전 비밀번호로 계속 열립니다. 유출이 걱정되면 저장소 기록 정리가 필요합니다.
- 페이지에는 `noindex` 메타 태그가 있어 검색엔진 노출을 막지만, 링크만으로 열리는 것은 비밀번호가 막아 줍니다.
